# прототип 1 від чатгпт — передача проєкту

Це фотокіоск самообслуговування Богдана у Славутичі. Дозволено переписувати інтерфейс і структуру коду за завданням власника. Не втрачайте підтверджені покупки, авторську геометрію, креслення та особисті зміни користувача.

## Почніть тут

Репозиторій: https://github.com/BogdanVcode/fotobudka-dashboard (main).
Сайт: https://bogdanvcode.github.io/fotobudka-dashboard/ .

Потрібен лише Node.js 20 або новіший. Після клонування:

```sh
npm run build
npm test
npm start
```

Відкрити http://localhost:4173 . Пакети npm, API-ключі, Blender або обліковий запис OpenAI для запуску сайту не потрібні. Для зміни .blend потрібен Blender. Код Three.js уже у vendor/.

Суфікси 09/10 у назвах файлів — історичні. Вони не означають, що ці файли застарілі. Інші старі app/model/budget JS у корені не підключені до поточного index.html; їх можна прибрати при переписуванні після перевірки посилань.

`docs/budget/current.json` — редаговане джерело поточного плану. `scripts/build-budget.mjs` створює budget10.js. Старі окремі кошики order.json, assembly-shopping.json та electronics-shopping-P2.json позначені архівними; не відновлюйте з них покупки. `engineering-source/` — історичні інженерні сценарії, не поточна збірка. Не запускайте одноразові register-* або refresh/prepare-* сценарії.

## Облік грошей

Підтверджений підсумок на момент передачі: 106 932,34 грн, із них доставка/комісії 1 248,67 грн. Оплачено, але не отримано: 57 543,65 грн; замовлено без оплати: 0 грн. Статус отримання не змінює витрати. Доставку рахуємо один раз на замовлення. Частини комплекту з `includedInOrderSubtotal` не мають окремої підтвердженої ціни — не додавайте їх повторно.

Інструменти вже є. Історичні витрати на них залишаються у фактичних покупках. Особистий EcoFlow не є активом кіоску: придбання окремого відкладено. DNP-папір замінено вибраним комплектом Citizen; його ціна невідома. Жодних нових цін у цьому оновленні не перевіряли.

`localStorage['fotobudka-budget-editor-v1']` — персональні зміни; GitHub Pages їх не синхронізує. Кнопка «Зберегти мої зміни» експортує JSON, «Відновити зміни» його імпортує. Перед переписуванням попросіть у власника експорт, якщо він редагував кошторис. Експорт не є заміною повного current.json.

При нових покупках оновіть первинний реєстр і відповідні рядки/замовлення в current.json; перевірте їх узгодженість тестом. Не змінюйте підтверджені витрати заради красивого підсумку.

## Відомі обмеження

- P2 — кандидат, не випробувана електроніка. Прошивки немає.
- ULN2003 виключено з покупок попереднім рішенням, але креслення STEP/DIR ще його містить. Інтерфейс Nano → DM556 треба узгодити, не проголошувати готовим.
- Модель купленого DC-DC і вихід PC817 потребують перевірки. NPN NO не виявляє всі обриви; утримання каретки без живлення не забезпечене самим датчиком.
- 3D — візуалізація авторського проєкту. Креслення ще не випущені у виробництво; кріплення, міцність і реальне обладнання звіряє майстер.
- Планові ціни — попередні оцінки, не підтвердження наявності. Невідомі ціни не входять у суми.
- Прибутковість — сценарій; не перевіряйте податки за графом або історичними даними без актуальних джерел.

## Публікація і доступ

GitHub Pages публікує корінь main. Після build/test коміт і push оновлюють сайт. Читання публічного репозиторію доступне без входу; push потребує власної авторизації GitHub у Claude. Ключі та токени не передавати в документах. Приватні receipts-local виключені; копії чеків отримувати від власника лише за потреби.

Цей пакет не імпортується до Claude автоматично. Дайте йому URL репозиторію або ZIP. Початковий запит: «Прочитай CLAUDE.md, запусти npm test, далі працюй за моїм завданням. Джерело бюджету docs/budget/current.json. Збережи підтверджені витрати та авторську геометрію».
