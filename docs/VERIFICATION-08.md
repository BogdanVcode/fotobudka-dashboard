# Перевірка 08

- SHA256 оригіналу звірено; вихідний файл не перезаписувався.
- 62 авторські меші: усі вершини і Dimensions звірено з Blender, допуск порівняння 0,001 мм.

- PDF: 16 аркушів A3, включно з 13 авторськими панелями; вибрані аркуші відрендерено та оглянуто.
- Перевірка не є розрахунком міцності, повною перевіркою колізій, фотометрією або підтвердженням обслуговування обладнання.
