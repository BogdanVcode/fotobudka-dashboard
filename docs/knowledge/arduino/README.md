# Бібліотека знань Arduino: AlexGyver

Додано 20.09.2026. Автор першоджерел — AlexGyver. [Каталог уроків](https://alexgyver.ru/lessons/). Це локальний тематичний покажчик і власні короткі нотатки для фотобудки, а не копія сайту, його платного контенту чи програмна бібліотека, встановлена в Arduino IDE.

Переглянуто структуру каталогу та відкриті матеріали, потрібні для підключення Nano, живлення, GPIO, механічного HOME, Serial і неблокувальних таймерів. Увесь сайт і відеокурс не пройдено. Прямі посилання нижче дозволяють продовжити дослідження без повторного пошуку.

## Як користуватися знаннями

1. Для загальних понять починати з відповідного уроку.
2. Для чисел, контактів і сумісності переходити до документації **конкретної моделі та ревізії**. Навчальний приклад не підтверджує сумісність нашого комплекту.
3. Проєктні рішення зберігати в MASTER-SPEC і документах модуля, не приписувати їх AlexGyver.
4. Після заміни плати повторно звіряти маркування, роз’єм і рівні сигналів. Відкрита стаття може змінитися.

## Уточнення для нашої схеми

- [C] Спільна земля потрібна між Nano та ULN2003. У запропонованому оптоізольованому інтерфейсі **окрему перемичку Nano GND → DM556 силовий GND не додаємо**. Загальне навчальне правило про GND не означає необхідність обходити оптоізоляцію.
- [C] HIGH на D2 відкриває колектор ULN2003 і створює струм у вході PUL; це не звичайний push-pull вихід 5 В. Треба перевірити напругу/струм оптовходу з реальним USB-живленням і падінням на ULN.
- [C] Розрив NC-кола дає такий самий рівень, як натиснутий HOME. Лише читання HIGH не є доказом знайденого нуля. Потрібна контрольована послідовність відпускання й повторного натискання з тайм-аутами.
- [C] Внутрішнє INPUT_PULLUP — стартовий варіант для короткого кабелю стенда. Якщо на довгому кабелі виникають завади, потрібна окрема ревізія входу з підтягуванням/фільтрацією; не маскувати їх лише великою програмною затримкою.
