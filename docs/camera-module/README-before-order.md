# Модуль Canon R50 · 700 мм

Дата: 20.09.2026. Статус: інженерне компонування для прототипу, не виробничий випуск.

Інтерактивна модель: `dashboard/camera-module/index.html`. Огляд для друку: `dashboard/camera-module/review.html`. Таблиця цін: `dashboard/camera-module/bom.json`.

Вхідне ТЗ: вертикальний TBD45-700, 57BYG250C-8, LJZ8-DS45-57, муфта 8×12 D25L30, 36 В, STEP/DIR, HOME NPN, USB MCU, портретний Canon R50, автоматичне наведення по голові. Текст ТЗ збережений поруч у `brief.txt`.

Обрано для першого стенду: 80 мм/с, 300 мм/с², 1/8 кроку, робочі межі 20–680 мм, HOME 10/3 мм/с, пауза перед фото 400 мс. Це початкові параметри для випробувань, не паспорт готової системи. Браузерна симуляція не керує апаратурою та не замінює прошивку MCU.

Напрямна 45×45×820 мм і каретка 104×90×26 мм взяті з продавця. Монтажні пластини, опори, місця болтів, контури кронштейна двигуна та камери умовні. Потрібні заводські креслення й перевірка посадки муфти. Камера показана вертикально. Зона кабелеукладача потребує близько 1000 мм; вікно для об’єктива при ході 700 мм — орієнтовно не менше 790 мм.

Новий вузол показано окремо. Габарити авторської кабінки та файл `БУДКА.blend` не змінені; інтеграцію нового ходу 700 мм із вирізом, освітленням і посадкою людини ще треба узгодити. У кошторисі не потрібно купувати одночасно старий TBD45-500 і новий TBD45-700.

П’ять позицій із перевіреними цінами: 7 925 грн. Плановий кошик з умовними резервами: 25 064 грн, із запасом 10% — 27 571 грн. Камера, об’єктив, ПК, EcoFlow, доставка, робота та випробування не входять. Резерв механічного захисту 6 000 грн не є комерційною пропозицією й може змінитися.

Невирішене перед виготовленням: крива моменту при 36 В, точна ревізія й наявність драйвера, отвори/вали/муфта, незалежне утримання каретки при втраті живлення або ременя, остаточний E-STOP, фізичні випробування HOME і відеопотоку. Утримувальний момент двигуна не дорівнює робочому моменту на швидкості. Гальмо на моторі не страхує обрив ременя.

Перевірки: `node tests/camera-module.mjs`, `node scripts/check-camera-module.mjs`. Генерація огляду: `node scripts/build-camera-module.mjs`.
