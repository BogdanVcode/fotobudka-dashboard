# Закупівля вертикального модуля · P2

P2 — єдина актуальна схема. P1 збережено тільки в архіві, її товари не додаються до кошторису.

ПК USB → Arduino Nano (USB 5 В), D2 STEP / D3 DIR → ULN2003 → DM556. D4 нижній HOME і D5 верхня межа: два HURON NPN NO через дві PC817/EL817. XL7015: 36 → 12 В для датчиків. Прошивки та фізичних випробувань немає.

## Перед складанням

- Кошторис містить кандидатів на монтаж, не перевірений готовий комплект.
- PC817/EL817: перевірити ізоляцію й вихід 0–5 В; X2 ULN2003 — прозвонити.
- Номінали захисту, мережевий монтаж, корпус і вентиляція потребують перевірки.
- [Інструменти та вибір «Позичу»](../../dashboard/camera-module/assembly-shopping.html). Деталі з цієї сторінки вже включені сюди, не додавати повторно. Інструменти рахуються окремо.
- [Архів P1](archive/P1-PIN-PURCHASES.md) — не для закупівлі.
