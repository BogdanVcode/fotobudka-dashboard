# Вертикальний модуль камери · P2

ПК USB → Arduino Nano (USB 5 В), D2 STEP / D3 DIR → ULN2003 → DM556. D4 нижній HOME і D5 верхня межа: два HURON NPN NO через дві PC817/EL817. XL7015: 36 → 12 В для датчиків. Прошивки та фізичних випробувань немає.

CNCPROM: товари, доставка й комісії оплачені; комплект отримано 25.09.2026. Повна витрата 10 116,68 грн.
