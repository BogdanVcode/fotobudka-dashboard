## Поточна ревізія 08

Геометрія: source/БУДКА.blend. 62 авторських об’єкти перенесені без зміни Dimensions і вершин. 51 доданих монтажних вузлів позначені окремо.

Переглядач: author-viewer.js; дані: design08.js; інтерфейс: current.js, current.css. Попередні app.js/model.js/design.js залишаються історичними файлами й не завантажуються головною сторінкою.

Креслення для узгодження. Присадка, кріплення, сервісні зазори й остаточні товщини ще не випущені у виробництво.

Папка engineering-source містить копії сценаріїв локального інженерного проєкту для аудиту. Це не автономний збірник цього статичного сайту: повний реєстр та інструменти залишаються в робочому проєкті.
