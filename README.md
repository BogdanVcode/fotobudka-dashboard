## Запуск

Потрібен Node.js 20+. Зовнішні пакети встановлювати не потрібно.

```sh
npm run build
npm test
npm start
```

Відкрити http://localhost:4173. GitHub Pages публікує корінь main.

Єдиний кошторис: `docs/budget/current.json`. Реєстр покупок: `docs/purchases/2026-09-25.json`. Персональні зміни браузера експортуються у вкладці «Кошторис».

`engineering-source/` та попередні ревізії — історія. Не використовувати старі окремі списки покупок. Поточні файли й обмеження описані в CLAUDE.md. Оригінал Blender і креслення збережені.
